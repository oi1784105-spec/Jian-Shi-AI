# 简试统一前端设计

## What We're Building

将 Stitch 的极简液态玻璃视觉系统扩展到用户端和管理后台全部页面，并增加白昼/黑夜主题与中文/英文切换。现有 Vue 路由、Pinia 状态、API 请求和业务流程保持不变。

## Why This Approach

项目目前使用 Vue 单文件组件和普通 CSS。使用 CSS 变量建立设计令牌，比直接移植 Stitch 的 Tailwind CDN 页面更贴合现有架构，构建改动更少，也能让两个独立前端保持一致。

## Key Decisions

- 白昼主题复用 Stitch 的黑白、玻璃边缘和高留白规范；黑夜主题使用对应的深色变量，不改变组件结构。
- 两个前端分别维护轻量偏好状态，主题和语言写入 `localStorage`，首次访问尊重系统主题。
- 使用 `vue-i18n` 管理中英文，使用 `lucide-vue-next` 替换表情和手绘图标。
- 用户端采用玻璃顶栏和页脚；管理端采用桌面侧边栏与移动端顶栏。
- 翻译固定界面文案、枚举、日期和确认提示；AI 报告正文与后端自由文本保持原文。
- 不创建营销首页，不修改后端接口，不改变业务数据结构。
- 通过生产构建和真实浏览器截图验证桌面/移动、亮/暗、中文/英文组合。

## Open Questions

无。用户已确认用户端和管理后台全部统一改造。
